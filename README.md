# Adutiya Portfolio — 3D React Starter

A responsive developer portfolio with a hovering 3D robot built from Three.js meshes using React Three Fiber, subtle Framer Motion reveals, project cards, skills, and contact CTA.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before publishing
- Replace `hello@example.com` in `src/main.jsx` with your real contact email.
- Add real project repository/demo URLs to the project cards.
- Add your resume PDF and update the links if you want a resume download.

Deploy to Vercel by importing the repository; Vite defaults should be detected automatically.
